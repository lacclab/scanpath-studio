38# DATA-16 / audit S5. Up to this many rows the fingerprint hashes the WHOLE 

39# frame, so any edit anywhere changes the key. Measured on a 4-column frame: 

40# 8 ms at 100k rows, 59 ms at 1M, 237 ms at 5M — and roughly six corpus-sized 

41# fingerprints are taken per rerun, so a full hash of a multi-million-row corpus 

42# would cost seconds of latency on every interaction. 200k keeps the exact path 

43# under ~16 ms while covering the case that actually matters: a user editing 

44# their own table and re-uploading it. 

45_FINGERPRINT_FULL_MAX_ROWS = 200_000 

46# Above the threshold: rows sampled from each end, plus an evenly-spaced stride. 

47_FINGERPRINT_EDGE_ROWS = 64 

48_FINGERPRINT_STRIDE_ROWS = 256 

49 

50# PERF-3. Per-run memo, `id(frame) -> (frame, fingerprint)`. 

51# 

52# Once the expensive subtabs went lazy the biggest remaining cost in a rerun was 

53# the cache keys themselves: ~26 calls, 43% of the run, and the same handful of 

54# frame OBJECTS over and over — every `_c_*` wrapper re-fingerprints the words 

55# and fixations frames `app.main` loaded once. Hashing the same object twice in 

56# one run cannot produce two answers, so the second hash onwards is pure waste. 

57# 

58# Entries hold a **weak** reference to the frame, and the `is` re-check below is 

59# what makes an `id()` key safe: a collected frame's id may be reissued to 

60# another object, but the entry's ref is dead by then, so the lookup misses. A 

61# strong reference would work too — and did, at first — but it pins every frame 

62# it has seen. That is worse than it sounds here: `st.cache_data` hands out a 

63# fresh object per call, so each run's corpus frames are new objects, and a 

64# strong memo kept up to `_FINGERPRINT_MEMO_MAX` of them alive from the end of 

65# one run until the top of the next — i.e. for a session's whole idle time, on 

66# frames that used to be freed the moment `main()` returned. 

67# 

68# `threading.local` scopes it to the ScriptRunner thread — one per Streamlit 

69# session — so two sessions never share entries and one session's reset can't 

70# drop another's. `reset_fingerprint_memo()` at the top of `app.main` bounds the 

71# staleness window to a single script run. (Widget callbacks run *before* the 

72# script body, so the first fingerprints of a rerun — `controls._compute_trial_filters` 

73# — still see the previous run's entries. Harmless: an id hit implies object 

74# identity either way, and those frames are the ones about to be reused.) 

75# 

76# THE ASSUMPTION: a fingerprinted frame is not mutated **in place** part-way 

77# through a run. That holds today — the frames the app fingerprints are built by 

78# `normalize_*` / `filter_*` / `.copy()` and then only read; helpers that add 

79# columns (`aggregation.py`) do it to a local copy — and it is the within-run 

80# form of the DATA-16 / audit S5 hazard the sampling threshold above is about. 

81# If you ever add an in-place `frame[col] = …` to a long-lived frame, either 

82# copy instead or the caches downstream of it will serve pre-mutation results 

83# for the rest of that run. 

84_FINGERPRINT_MEMO = threading.local() 

85#: Backstop for a non-Streamlit caller (headless `api.py`, the CLI) that never 

86#: reaches `reset_fingerprint_memo`: keep the memo from growing without bound. 

87#: A rerun makes ~26 calls, so the app never reaches this; a bulk export does 

88#: (`compute_word_metrics` adds two entries per trial), which is why eviction is 

89#: least-recently-used rather than clear-everything — the latter threw away the 

90#: hot corpus frames to make room for per-trial temporaries. 

91_FINGERPRINT_MEMO_MAX = 64

99def frame_fingerprint(df: Optional[pd.DataFrame]) -> tuple: 

100 """Cheap, content-sensitive identity for a DataFrame. 

101 

102 Used as an *explicit* ``@st.cache_data`` key for functions that take an 

103 underscore-prefixed (un-hashed) frame argument — so Streamlit never re-hashes 

104 a multi-million-row frame on every rerun just to look up the cache. 

105 

106 **Up to ``_FINGERPRINT_FULL_MAX_ROWS`` the whole frame is hashed**, so any 

107 edit anywhere changes the key. This is the fix for DATA-16 / audit S5: the 

108 previous key sampled only the first and last 64 rows, so a table of ≥129 rows 

109 edited anywhere in between produced an *identical* key — not a probabilistic 

110 collision but a certain one. Re-uploading a corrected table of the same shape 

111 then served every figure, measure and aggregate from the pre-edit data, 

112 silently, which is a route to a wrong number in a paper. 

113 

114 **Above the threshold the key is a sample** (both ends plus an evenly-spaced 

115 stride) and detection becomes probabilistic: a single-cell edit in a 

116 5-million-row corpus has roughly a 1-in-19,000 chance of landing on a sampled 

117 row. That is a deliberate trade — a full hash there costs ~237 ms, taken 

118 about six times per rerun. It is the right trade because the frames people 

119 hand-edit and re-upload are their own tables, not multi-million-row public 

120 corpora, but it *is* a limit: after editing a corpus that large, use **Clear 

121 cache** in the ☰ menu. 

122 

123 The per-row hashes are digested **in order** rather than summed. Summing is 

124 order-invariant, so a frame and a ``sort_values`` of itself — same rows, same 

125 index labels, different order — used to share a key while producing different 

126 results downstream. 

127 

128 ``hash_pandas_object`` raises on columns of unhashable objects (lists/arrays — 

129 e.g. parquet-preserved span-index fields). We stringify and retry rather than 

130 drop the content signal entirely: zeroing the hash would collapse every frame 

131 of the same shape + columns to one fingerprint, serving stale cached results 

132 when switching between two such frames. If even that fails the key becomes 

133 *unique* rather than zero — an unhashable frame must miss the cache, not 

134 match every other frame of its shape. 

135 

136 **The same frame object is only hashed once per run** — see the 

137 ``_FINGERPRINT_MEMO`` note above for why that is safe and what it assumes. 

138 """ 

139 if df is None or getattr(df, "empty", True): 

140 return (0, ()) 

141 memo = getattr(_FINGERPRINT_MEMO, "cache", None) 

142 if memo is None: 

143 memo = _FINGERPRINT_MEMO.cache = OrderedDict() 

144 key = id(df) 

145 hit = memo.get(key) 

146 if hit is not None and hit[0]() is df: 

147 memo.move_to_end(key) 

148 return hit[1] 

149 value = _compute_frame_fingerprint(df) 

150 # Drop entries whose frame has already been collected before evicting a live 

151 # one — those are pure bookkeeping and cost nothing to lose. 

152 if len(memo) >= _FINGERPRINT_MEMO_MAX: 

153 for dead in [k for k, (ref, _) in memo.items() if ref() is None]: 

154 del memo[dead] 

155 while len(memo) >= _FINGERPRINT_MEMO_MAX: 

156 memo.popitem(last=False) 

157 memo[key] = (weakref.ref(df), value) 

158 return value

161def _compute_frame_fingerprint(df: pd.DataFrame) -> tuple: 

162 """The actual hash behind :func:`frame_fingerprint`, memo aside.""" 

163 cols = tuple(map(str, df.columns)) 

164 n = int(len(df)) 

165 

166 def _hash(sample: pd.DataFrame) -> str: 

167 try: 

168 per_row = pd.util.hash_pandas_object(sample, index=True) 

169 except TypeError: 

170 # Unhashable cell objects — stringify so content still drives the key. 

171 per_row = pd.util.hash_pandas_object(sample.astype(str), index=True) 

172 # Digest the per-row hashes in ORDER. Summing them (the previous 

173 # approach) is order-invariant, so a frame and a `sort_values` of itself 

174 # — same rows, same index labels, different order — produced the same 

175 # key while yielding different results downstream. 

176 return hashlib.blake2b( 

177 per_row.to_numpy(dtype="uint64").tobytes(), digest_size=16 

178 ).hexdigest() 

179 

180 try: 

181 if n <= _FINGERPRINT_FULL_MAX_ROWS: 

182 return (n, cols, _hash(df)) 

183 head = _hash(df.head(_FINGERPRINT_EDGE_ROWS)) 

184 tail = _hash(df.tail(_FINGERPRINT_EDGE_ROWS)) 

185 # An evenly-spaced sample of the whole frame, capped at 

186 # _FINGERPRINT_STRIDE_ROWS rows however long the table is. 

187 middle = _hash(df.iloc[:: max(1, n // _FINGERPRINT_STRIDE_ROWS)]) 

188 except Exception: 

189 # Fail CLOSED: a key nothing else can equal, so this frame simply doesn't 

190 # share a cache entry. `(n, cols, 0, 0)` failed *open* — every frame of 

191 # the same shape collided. 

192 return (n, cols, uuid.uuid4().hex) 

193 return (n, cols, head, tail, middle)

243def onestop_data_provenance(participant: Optional[str] = None) -> dict: 

244 """Where the currently-loaded OneStop data came from, for the Raw Data tab. 

245 

246 Parses `ONESTOP_DATA_DIR` (typically `…/onestop_<cohort>/reports/<source>/<date>/full/`) 

247 to surface cohort, export source (lacclab / public / osf), and date in the 

248 UI so reviewers can verify they're looking at the right export. Also 

249 reports the per-pid shard's mtime when a participant is set — that's the 

250 timestamp of the actual data the page is currently rendering. 

251 

252 Returns an empty dict when `ONESTOP_DATA_DIR` is unset (i.e. the OneStop 

253 data source isn't in use — caller should suppress the provenance panel). 

254 """ 

255 base = onestop_data_dir() 

256 if base is None: 

257 return {} 

258 

259 info: dict = {"data_dir": str(base)} 

260 

261 # Best-effort parse of the canonical path layout. 

262 parts = base.resolve().parts 

263 try: 

264 # Look for "reports" anchor and grab source/date after it. 

265 i = parts.index("reports") 

266 info["source"] = parts[i + 1] # lacclab / public / osf 

267 info["date"] = parts[i + 2] # YYYYMMDD 

268 except (ValueError, IndexError): 

269 pass 

270 for p in parts: 

271 if p.startswith("onestop_"): 

272 info["cohort"] = p.removeprefix("onestop_") # L1 / L2 

273 break 

274 

275 # Reports the per-pid shard's mtime when a participant is set — that's the 

276 # timestamp of the bytes the page is rendering right now. 

277 if participant: 

278 ia_shard, fix_shard = _onestop_shard_paths(base, participant) 

279 info["loaded_from"] = "per-pid shard" 

280 info["ia_shard"] = str(ia_shard) 

281 info["fix_shard"] = str(fix_shard) 

282 if ia_shard.is_file(): 

283 info["ia_shard_mtime"] = ia_shard.stat().st_mtime 

284 if fix_shard.is_file(): 

285 info["fix_shard_mtime"] = fix_shard.stat().st_mtime 

286 else: 

287 ia_csv = base / "ia_Paragraph.csv.zip" 

288 fix_csv = base / "fixations_Paragraph.csv.zip" 

289 info["loaded_from"] = "full CSV.zip export" 

290 if ia_csv.is_file(): 

291 info["ia_shard"] = str(ia_csv) 

292 info["ia_shard_mtime"] = ia_csv.stat().st_mtime 

293 if fix_csv.is_file(): 

294 info["fix_shard"] = str(fix_csv) 

295 info["fix_shard_mtime"] = fix_csv.stat().st_mtime 

296 return info

299@st.cache_data(show_spinner="Loading OneStop lacclab export…") 

300def load_onestop_server_bundle( 

301 participant: Optional[str] = None, 

302) -> Tuple[pd.DataFrame, pd.DataFrame]: 

303 """Load OneStop lacclab IA + fixation reports from `$ONESTOP_DATA_DIR`. 

304 

305 Fast path — when `participant` is given and per-pid shards exist under 

306 `<ONESTOP_DATA_DIR>/by_pid/{ia,fixations}/<pid>.parquet`, load just that 

307 one participant (sub-second). Shards are generated by 

308 `python -m scanpath_studio.onestop_shard --data-dir <ONESTOP_DATA_DIR>`. 

309 

310 Slow path — fall back to loading the full CSV.zip exports (~3 min, ~60 GB 

311 RAM for the L2 cohort). Used when no participant is specified, or when 

312 a deep link points at a pid whose shard hasn't been generated yet. 

313 """ 

314 base = onestop_data_dir() 

315 if base is None: 

316 return pd.DataFrame(), pd.DataFrame() 

317 

318 # Fast path: per-pid shards. 

319 if participant: 

320 ia_shard, fix_shard = _onestop_shard_paths(base, participant) 

321 ia_present = ia_shard.exists() 

322 fix_present = fix_shard.exists() 

323 if ia_present and fix_present: 

324 return pd.read_parquet(ia_shard), pd.read_parquet(fix_shard) 

325 # NEVER fall through to the 15 GB load when a participant is named — 

326 # the deep link is for one pid only, so loading the whole cohort just 

327 # to discover the pid still has no data is pure waste. Surface a clear 

328 # error and stop. Common cause: pid was excluded from the IA report 

329 # (no exported reading data), or shards haven't been generated yet. 

330 missing = [ 

331 p.name 

332 for p, ok in [(ia_shard, ia_present), (fix_shard, fix_present)] 

333 if not ok 

334 ] 

335 st.error( 

336 f"No scanpath data for participant {participant!r}. " 

337 f"Missing shards: {', '.join(missing)}. " 

338 f"If the pid was added since the last shard run, regenerate with: " 

339 f"`python -m scanpath_studio.onestop_shard --data-dir <ONESTOP_DATA_DIR>`. " 

340 f"Pids with no IA report (e.g. metadata-status excluded) cannot be visualized." 

341 ) 

342 st.stop() 

343 

344 # Slow path: full CSV.zip load. 

345 ia_path = base / "ia_Paragraph.csv.zip" 

346 fix_path = base / "fixations_Paragraph.csv.zip" 

347 if not ia_path.exists() or not fix_path.exists(): 

348 st.error( 

349 f"OneStop data not found under {base}. Expected ia_Paragraph.csv.zip + " 

350 f"fixations_Paragraph.csv.zip." 

351 ) 

352 return pd.DataFrame(), pd.DataFrame() 

353 words = pd.read_csv(ia_path, low_memory=False) 

354 fixations = pd.read_csv(fix_path, low_memory=False) 

355 return words, fixations

358def _norm_col(name) -> str: 

359 """Fold a column name to its case- and separator-insensitive key. 

360 

361 Lowercases and drops every non-alphanumeric char, so ``IA_LEFT``, 

362 ``ia_left``, ``Ia-Left`` and ``ia left`` all collapse to ``ialeft`` — 

363 letting auto-detection match real-world column names that differ only in 

364 capitalization or word separators.""" 

365 return re.sub(r"[^a-z0-9]", "", str(name).lower())

368def pick_column(df: pd.DataFrame, candidates: Iterable[str]) -> Optional[str]: 

369 """Return the first matching column name from a candidate list. 

370 

371 Matching is case- and separator-insensitive (see ``_norm_col``). Candidate 

372 order is still priority order — the first candidate with any match wins (so 

373 EyeLink names keep beating Gazepoint), and among equally-normalized columns 

374 the leftmost one wins.""" 

375 lookup: Dict[str, str] = {} 

376 for col in df.columns: 

377 lookup.setdefault(_norm_col(col), col) 

378 for name in candidates: 

379 hit = lookup.get(_norm_col(name)) 

380 if hit is not None: 

381 return hit 

382 return None

695def split_source_file( 

696 df: pd.DataFrame, 

697 *, 

698 delimiter: str = "_",

700 prefix: str = FILE_PART_PREFIX,

722def extract_columns_from_source_file( 

723 df: pd.DataFrame, 

724 pattern: str, 

725 *, 

726 column: str = SOURCE_FILE_COLUMN, 

727 lowercase: bool = False, 

728) -> pd.DataFrame: 

729 """Add one column per *named group* of a regex applied to ``source_file``. 

730 

731 Sibling of :func:`split_source_file` for filenames whose fields are 

732 positionally irregular — varying-length parts or an optional prefix make a 

733 fixed delimiter split unreliable. A regex with named groups, e.g. 

734 ``r"(?P<session>\\d+_\\w+_ET\\d)_.*_(?P<stimulus>.+)_scanpath"``, extracts each 

735 group into its own column the wizard can then map as a trial / participant id. 

736 ``lowercase`` folds the captured values (useful when one table names a field 

737 CamelCase and another lowercase). No-op (returns ``df`` unchanged) when 

738 ``column`` is absent, ``pattern`` is empty / uncompilable, or it declares no 

739 named groups; rows that don't match get NaN. A named group that collides with 

740 an existing column is **skipped** (the real data wins) — see 

741 :func:`source_file_regex_collisions` to surface those in a UI.""" 

742 if not pattern or column not in df.columns: 

743 return df 

744 try: 

745 compiled = re.compile(pattern) 

746 except re.error: 

747 return df 

748 if not compiled.groupindex: 

749 return df 

750 extracted = df[column].astype(str).str.extract(compiled) 

751 df = df.copy() 

752 for group in compiled.groupindex: # named groups only 

753 if group in df.columns: # don't clobber an existing data column 

754 continue 

755 values = extracted[group] 

756 if lowercase: 

757 values = values.str.lower() 

758 df[group] = values.to_numpy() 

759 return df

763 """Named groups of ``pattern`` that already exist as columns in ``df``. 

764 

765 :func:`extract_columns_from_source_file` skips these (so it never clobbers 

766 real data); the wizard surfaces them so the user can rename the group."""

776def aggregate_char_boxes( 

777 df: pd.DataFrame, schema: Dict[str, Optional[str]] 

778) -> pd.DataFrame: 

779 """Collapse character-level AOI rows into one bounding box per word. 

780 

781 For interest-area tables shipped one row per *character* (e.g. CJK corpora 

782 that have no whitespace word boundaries), aggregate the characters of each 

783 word — grouped by the mapped trial id + word id (plus participant / text id 

784 when mapped) — into a single bounding box: min/max over the mapped box columns, 

785 first value of every other column. Run this on the RAW frame *before* 

786 :func:`normalize_words` (which expects one row per word box). ``schema`` is a 

787 word schema dict (field → source column). Returns ``df`` unchanged when the 

788 trial or word-id column isn't mapped, or no box columns are.""" 

789 word_col = schema.get("word_id") 

790 trial = schema.get("trial") 

791 if not word_col or not trial: 

792 return df 

793 group_cols = list(trial_mapping_columns(trial)) 

794 for key in ("participant", "text_id"): 

795 mapped = schema.get(key) 

796 if mapped: 

797 group_cols += trial_mapping_columns(mapped) 

798 group_cols.append(word_col) 

799 # De-dup, keep only columns actually present, and require the word id. 

800 group_cols = [c for c in dict.fromkeys(group_cols) if c in df.columns] 

801 if word_col not in group_cols: 

802 return df 

803 

804 has_xywh = all(schema.get(k) for k in ("x", "y", "width", "height")) 

805 has_edges = all(schema.get(k) for k in ("left", "right", "top", "bottom")) 

806 if not has_xywh and not has_edges: 

807 return df 

808 

809 df = df.copy() 

810 if has_xywh: 

811 left = pd.to_numeric(df[schema["x"]], errors="coerce") 

812 top = pd.to_numeric(df[schema["y"]], errors="coerce") 

813 df["_box_l"], df["_box_t"] = left, top 

814 df["_box_r"] = left + pd.to_numeric(df[schema["width"]], errors="coerce") 

815 df["_box_b"] = top + pd.to_numeric(df[schema["height"]], errors="coerce") 

816 else: 

817 df["_box_l"] = pd.to_numeric(df[schema["left"]], errors="coerce") 

818 df["_box_r"] = pd.to_numeric(df[schema["right"]], errors="coerce") 

819 df["_box_t"] = pd.to_numeric(df[schema["top"]], errors="coerce") 

820 df["_box_b"] = pd.to_numeric(df[schema["bottom"]], errors="coerce") 

821 

822 temp = {"_box_l", "_box_r", "_box_t", "_box_b"} 

823 agg = {c: "first" for c in df.columns if c not in group_cols and c not in temp} 

824 agg.update(_box_l="min", _box_t="min", _box_r="max", _box_b="max") 

825 out = df.groupby(group_cols, sort=False, as_index=False).agg(agg) 

826 

827 # Write the aggregated box back into the SAME schema columns so the existing 

828 # word schema still maps it (origin+size or edges, matching the input form). 

829 if has_xywh: 

830 out[schema["x"]] = out["_box_l"] 

831 out[schema["y"]] = out["_box_t"] 

832 out[schema["width"]] = out["_box_r"] - out["_box_l"] 

833 out[schema["height"]] = out["_box_b"] - out["_box_t"] 

834 else: 

835 out[schema["left"]] = out["_box_l"] 

836 out[schema["right"]] = out["_box_r"] 

837 out[schema["top"]] = out["_box_t"] 

838 out[schema["bottom"]] = out["_box_b"] 

839 return out.drop(columns=list(temp))

842def _read_by_extension(buf, name: str) -> pd.DataFrame: 

843 """Dispatch a buffer/path to a pandas reader by its (lowercased) name. 

844 

845 CSV/TSV reads pass ``low_memory=False`` so pandas infers one dtype per 

846 column in a single pass. The default chunked parser can otherwise read the 

847 same column as numeric in early chunks and as strings in a later chunk that 

848 holds a sentinel (e.g. EyeLink's ``.`` in ``CURRENT_FIX_PRECISION_MEASURE_*``

851 pyarrow when Streamlit serializes the frame for display — only on large 

852 (multi-chunk) files, which is why a small upload reads fine locally but a

863 return pd.read_csv(buf, low_memory=False)

892# DATA-16 (security review S6): bound zip decompression. `_read_zipped_table` 

893# used to `read()` every member with no ceiling, so a small archive of highly 

894# compressible CSV could expand to many gigabytes and OOM-kill the process — on 

895# the ~1 GB hosted demo that takes every concurrent visitor's session with it. 

896# The limits are deliberately generous: real eye-tracking exports are large (the 

897# OneStop reports are hundreds of MB to a few GB of CSV per zipped table), so the 

898# absolute caps only catch the honestly-enormous case, and the *ratio* is what 

899# actually distinguishes a zip bomb from a big corpus. 

900ZIP_MAX_MEMBER_UNCOMPRESSED_BYTES = 4 * 1024**3 # 4 GB for any single member 

901ZIP_MAX_TOTAL_UNCOMPRESSED_BYTES = 8 * 1024**3 # 8 GB across the whole archive 

902ZIP_MAX_COMPRESSION_RATIO = 200.0 # uncompressed / compressed 

903# Below this the ratio is not checked at all: a small but very repetitive table 

904# can legitimately compress 1000×, and expanding it costs nothing. 

905ZIP_RATIO_CHECK_MIN_BYTES = 256 * 1024 * 1024

908def _format_bytes(n: float) -> str: 

909 """Human-readable byte size for a user-facing error message.""" 

910 for unit in ("B", "KB", "MB", "GB"): 

911 if abs(n) < 1024 or unit == "GB": 

912 return f"{n:.0f} {unit}" if unit == "B" else f"{n:.1f} {unit}" 

913 n /= 1024.0 

914 return f"{n:.1f} GB"

917def _check_zip_limits(infos: List[zipfile.ZipInfo]) -> None: 

918 """Reject an archive that would decompress past the DATA-16 limits. 

919 

920 Checks the *declared* sizes (``ZipInfo.file_size``) before a single member is 

921 opened, so an oversized archive fails fast instead of being discovered by 

922 exhausting RAM. Declared sizes can be forged, so :func:`_read_zipped_table` 

923 additionally reads each member under a hard byte budget. 

924 """ 

925 total = sum(int(i.file_size) for i in infos) 

926 compressed = sum(int(i.compress_size) for i in infos) 

927 for info in infos: 

928 if int(info.file_size) > ZIP_MAX_MEMBER_UNCOMPRESSED_BYTES: 

929 raise ValueError( 

930 f"{info.filename!r} in the zip archive expands to " 

931 f"{_format_bytes(info.file_size)}, above the per-file limit of " 

932 f"{_format_bytes(ZIP_MAX_MEMBER_UNCOMPRESSED_BYTES)}. Unzip it " 

933 "and load the table directly, or split it into smaller files." 

934 ) 

935 if total > ZIP_MAX_TOTAL_UNCOMPRESSED_BYTES: 

936 raise ValueError( 

937 f"the zip archive expands to {_format_bytes(total)}, above the " 

938 f"{_format_bytes(ZIP_MAX_TOTAL_UNCOMPRESSED_BYTES)} decompression " 

939 "limit. Unzip it and load the tables directly, or split the archive." 

940 ) 

941 if total >= ZIP_RATIO_CHECK_MIN_BYTES: 

942 ratio = total / max(compressed, 1) 

943 if ratio > ZIP_MAX_COMPRESSION_RATIO: 

944 raise ValueError( 

945 f"the zip archive expands {ratio:.0f}× (to " 

946 f"{_format_bytes(total)}), above the " 

947 f"{ZIP_MAX_COMPRESSION_RATIO:.0f}× limit — it doesn't look like " 

948 "a normal data export. Unzip it and load the tables directly if " 

949 "this is genuine." 

950 )

953def _read_zipped_table(file_like_or_path) -> pd.DataFrame: 

954 """Read table(s) from a ``.zip`` archive (e.g. ``data.csv.zip``). 

955 

956 Each member is dispatched on its own extension, so a zip may wrap any 

957 supported format. A multi-member archive is concatenated just like a 

958 multi-file upload — every member's rows tagged with its stem in 

959 ``source_file``. pandas infers compression only from string paths, not from 

960 uploaded file-like objects, so we open the archive ourselves. Raises 

961 ``ValueError`` if the archive holds no data file (macOS ``__MACOSX``/dotfile 

962 cruft is ignored), or if it would decompress past the DATA-16 size limits 

963 (``ZIP_MAX_*``) — both the declared sizes and the bytes actually read are 

964 bounded, so a forged header can't slip past.""" 

965 with zipfile.ZipFile(file_like_or_path) as zf: 

966 infos = [ 

967 i 

968 for i in zf.infolist() 

969 if not i.is_dir() and not Path(i.filename).name.startswith((".", "__")) 

970 ] 

971 if not infos: 

972 raise ValueError("the zip archive contains no readable table files") 

973 _check_zip_limits(infos) 

974 remaining = ZIP_MAX_TOTAL_UNCOMPRESSED_BYTES 

975 frames, labels = [], [] 

976 for info in infos: 

977 member = info.filename 

978 with zf.open(info) as inner: 

979 # Read one byte past the budget: if we get it, the member lied 

980 # about its declared size and the archive is rejected. 

981 payload = inner.read(remaining + 1) 

982 if len(payload) > remaining: 

983 raise ValueError( 

984 f"{member!r} in the zip archive decompresses past the " 

985 f"{_format_bytes(ZIP_MAX_TOTAL_UNCOMPRESSED_BYTES)} limit " 

986 "(its declared size was wrong). Refusing to read it." 

987 ) 

988 remaining -= len(payload) 

989 frames.append(_read_by_extension(io.BytesIO(payload), member.lower())) 

990 labels.append(Path(member).stem) 

991 return _tag_and_concat(frames, labels, SOURCE_FILE_COLUMN)

1393def detect_word_id_offset(words: pd.DataFrame, fixations: pd.DataFrame) -> int: 

1394 """Detect a 1-based fixation ``word_id`` against 0-based word boxes (BUG-8). 

1395 

1396 Some exports (the bundled OneStop demo among them) number the fixation 

1397 report's word column ``1..N`` while the interest-area table numbers its rows 

1398 ``0..N-1``, so every fixation's pre-assigned ``word_id`` points at the *next* 

1399 word. ``measures.assign_fixations_to_words`` keeps existing ids, so the 

1400 computed reading measures then attach to the wrong words. 

1401 

1402 Returns the offset to **subtract** from the fixation word ids: ``1`` when the 

1403 shift is unambiguous, ``0`` (by far the common case) otherwise. A false 

1404 positive silently corrupts a correct dataset, so the test is deliberately 

1405 strict — every condition below must hold across the whole dataset: 

1406 

1407 * both frames carry whole-number ``word_id`` values, 

1408 * the words ids start at ``0`` and the fixation ids start at ``1``, 

1409 * *every* trial present in both frames has 0-based, gap-free word ids and no 

1410 fixation id below ``1`` or more than one past its last word, and 

1411 * at least one trial actually overflows by exactly one 

1412 (``max fixation id == max word id + 1``) — without that there is no 

1413 evidence of a shift, just a reader who never looked at the first word. 

1414 """ 

1415 if words is None or fixations is None or words.empty or fixations.empty: 

1416 return 0 

1417 keys = grouping_columns(words) 

1418 if keys != grouping_columns(fixations): 

1419 return 0 

1420 needed = set(keys) | {"word_id"} 

1421 if not needed.issubset(words.columns) or not needed.issubset(fixations.columns): 

1422 return 0 

1423 w_ids = pd.to_numeric(words["word_id"], errors="coerce").dropna() 

1424 f_ids = pd.to_numeric(fixations["word_id"], errors="coerce").dropna() 

1425 if w_ids.empty or f_ids.empty: 

1426 return 0 

1427 # Fractional ids (character-level indices, say) aren't a word numbering we 

1428 # can reason about. 

1429 if not (w_ids % 1 == 0).all() or not (f_ids % 1 == 0).all(): 

1430 return 0 

1431 if float(w_ids.min()) != 0.0 or float(f_ids.min()) != 1.0: 

1432 return 0 

1433 # Project onto (keys + id) rather than .assign()-ing onto the source frames: 

1434 # the OneStop words/fixations tables are wide, and this runs on every load. 

1435 w_stats = ( 

1436 _key_frame(words, w_ids).groupby(keys, sort=False)["_id"].agg(_WORD_ID_AGGS) 

1437 ) 

1438 f_stats = ( 

1439 _key_frame(fixations, f_ids) 

1440 .groupby(keys, sort=False)["_id"] 

1441 .agg(["min", "max"]) 

1442 ) 

1443 joined = w_stats.join(f_stats, how="inner", lsuffix="_w", rsuffix="_f") 

1444 if joined.empty: 

1445 return 0 

1446 zero_based = joined["min_w"] == 0 

1447 gap_free = joined["nunique"] == joined["max_w"] + 1 

1448 in_range = joined["min_f"] >= 1 

1449 overflow = joined["max_f"] == joined["max_w"] + 1 

1450 runaway = joined["max_f"] > joined["max_w"] + 1 

1451 if not (zero_based.all() and gap_free.all() and in_range.all()): 

1452 return 0 

1453 if runaway.any() or not overflow.any(): 

1454 return 0 

1455 return 1

1558def derive_trial_index(frame: pd.DataFrame) -> pd.Series: 

1559 """Per-participant 1-based trial order, aligned to ``frame``'s rows. 

1560 

1561 Prefers an existing ``trial_index`` / ``TRIAL_INDEX`` column (the order the 

1562 data already records). Otherwise it ranks each participant's trials by their 

1563 earliest ``timestamp_ms`` (falling back to first-appearance order when no 

1564 timestamps) and numbers them 1, 2, 3, …. Used by the Corpus Analysis tab to 

1565 plot a metric as a function of where the trial fell in the session. Returns a 

1566 float Series (NaN where the index can't be determined).""" 

1567 if frame.empty or not {"participant_id", "trial_id"} <= set(frame.columns): 

1568 return pd.Series([np.nan] * len(frame), index=frame.index, dtype="float64") 

1569 for col in ("trial_index", "TRIAL_INDEX"): 

1570 if col in frame.columns: 

1571 return pd.to_numeric(frame[col], errors="coerce") 

1572 if "timestamp_ms" in frame.columns: 

1573 order_key = frame.groupby(["participant_id", "trial_id"])[ 

1574 "timestamp_ms" 

1575 ].transform("min") 

1576 else: 

1577 # First-appearance order: row position of each trial's first row. 

1578 order_key = pd.Series(range(len(frame)), index=frame.index) 

1579 order_key = ( 

1580 frame.assign(_k=order_key) 

1581 .groupby(["participant_id", "trial_id"])["_k"] 

1582 .transform("min") 

1583 ) 

1584 per_trial = ( 

1585 frame[["participant_id", "trial_id"]] 

1586 .assign(_k=pd.to_numeric(order_key, errors="coerce")) 

1587 .drop_duplicates(["participant_id", "trial_id"]) 

1588 .sort_values(["participant_id", "_k"]) 

1589 ) 

1590 per_trial["_idx"] = per_trial.groupby("participant_id").cumcount() + 1 

1591 merged = frame[["participant_id", "trial_id"]].merge( 

1592 per_trial[["participant_id", "trial_id", "_idx"]], 

1593 on=["participant_id", "trial_id"], 

1594 how="left", 

1595 ) 

1596 return pd.Series( 

1597 pd.to_numeric(merged["_idx"], errors="coerce").to_numpy(), 

1598 index=frame.index, 

1599 dtype="float64",

1801def coerce_flag(col: pd.Series) -> pd.Series: 

1802 """Coerce a flag-like column to real booleans (BUG-7). 

1803 

1804 Numbers go by ``!= 0``; strings are matched against the sentinels above 

1805 (case-insensitively) rather than by truthiness. NaN / missing is ``False``, 

1806 which is what every downstream flag consumer already assumed. 

1807 """ 

1808 if pd.api.types.is_bool_dtype(col): 

1809 return col.fillna(False).astype(bool) 

1810 numeric = pd.to_numeric(col, errors="coerce") 

1811 if numeric.notna().any(): 

1812 # A numeric-looking column ('0'/'1', 0/1, 0.0/1.0): non-zero is True. 

1813 # Values that didn't parse fall through to the string test below, so a 

1814 # mixed '0'/'1'/'.' column doesn't lose its '.' rows to True. 

1815 parsed = numeric.notna() 

1816 # Build the boolean array positionally: assigning a bool ndarray into a 

1817 # bool Series by mask is deprecated in pandas as a dtype-incompatible set. 

1818 values = (numeric.to_numpy() != 0) & parsed.to_numpy() 

1819 unparsed = (~parsed & col.notna()).to_numpy() 

1820 if unparsed.any(): 

1821 values[unparsed] = ~( 

1822 col[unparsed] 

1823 .astype(str) 

1824 .str.strip() 

1825 .str.lower() 

1826 .isin(_FALSEY_FLAG_STRINGS) 

1827 ).to_numpy() 

1828 result = pd.Series(values, index=col.index, dtype=bool) 

1829 return result 

1830 return ( 

1831 ~col.fillna("").astype(str).str.strip().str.lower().isin(_FALSEY_FLAG_STRINGS) 

1832 ).astype(bool)

1939def normalize_words( 

1940 words: pd.DataFrame, schema: Dict[str, str], *, keep_columns: Optional[set] = None 

1941) -> pd.DataFrame: 

1942 # The explicit index makes scalar assignments (e.g. the stimulus-level 

1943 # participant placeholder) fill every row even when assigned first. 

1944 df = pd.DataFrame(index=words.index) 

1945 if schema.get("participant"): 

1946 # str or list (a composite participant id, joined like the trial id). 

1947 df["participant_id"] = trial_id_series(words, schema["participant"]) 

1948 else: 

1949 # Stimulus-level word/AoI table (one row per word per text, shared by 

1950 # all participants) — broadcast_stimulus_words() expands it across the 

1951 # participants found in the fixations. 

1952 df["participant_id"] = STIMULUS_PARTICIPANT 

1953 df[STIMULUS_WORDS_FLAG] = True 

1954 trial_cols = trial_mapping_columns(schema["trial"]) 

1955 if len(trial_cols) > 1: 

1956 # User-composed unique trial ID: authoritative, so it wins over a raw 

1957 # `unique_trial_id` column and needs no repeated-reading suffixing. 

1958 df["trial_id"] = trial_id_series(words, trial_cols) 

1959 df["unique_trial_id"] = df["trial_id"] 

1960 else: 

1961 trial_col = ( 

1962 "unique_trial_id" if "unique_trial_id" in words.columns else trial_cols[0] 

1963 ) 

1964 df["trial_id"] = words[trial_col].astype(str) 

1965 if schema.get("participant"): 

1966 df = _disambiguate_repeated_readings(df, words, trial_col) 

1967 if "unique_trial_id" in words.columns: 

1968 df["unique_trial_id"] = words["unique_trial_id"].astype(str) 

1969 if "unique_paragraph_id" in words.columns: 

1970 df["unique_text_id"] = words["unique_paragraph_id"].astype(str) 

1971 df["text_id"] = df["unique_text_id"] 

1972 elif schema.get("text_id"): 

1973 # str or list (a composite text id, joined like the trial id). 

1974 df["text_id"] = trial_id_series(words, schema["text_id"]) 

1975 else: 

1976 df["text_id"] = df["trial_id"] 

1977 df = _copy_screen_fields(df, words, schema) 

1978 df["word_id"] = pd.to_numeric(words[schema["word_id"]], errors="coerce") 

1979 if schema.get("text"): 

1980 df["text"] = words[schema["text"]].astype(str)
