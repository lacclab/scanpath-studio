# Compare groups or conditions

Compare a reading measure between two groups of participants or two conditions.

1. [Select the trials](index.md#before-you-start), then open
   :material/bar_chart: **Corpus Analysis** → **Groups**.
2. Turn on **Compare a second group**.
3. Choose **Split a field** to form the groups from the values of one column,
   or **Independent filter sets** to define each group by a separate set of filters.
4. In **View**, choose **Group means & difference** and a measure. Check the
   number of participants in each group and whether any participant is in
   both. The **Standardized difference** (Cohen's d) is shown only when the
   groups share no participant.
5. [Download the table and recipe](index.md#keep-the-result).

The comparison is descriptive. It runs no significance test.
For a recorded example, see [Analyze one text](analyze-one-text.md).
