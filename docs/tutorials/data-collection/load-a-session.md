# Load a session

The first step for every data-collection check: get the session into the app,
with the screen it was recorded on.

1. On the :material/database: **Data Management** page select
   **:material/add: Add dataset → Import files**.
2. Upload the Words (interest areas) and Fixations tables.
3. Check the proposed columns and the **Recording setup**: the monitor
   resolution the session was actually recorded at. Every position in the plot
   is drawn on that screen.
4. Select **:material/check: Add dataset**.

If the dataset is already loaded, click its row in the list of datasets.
