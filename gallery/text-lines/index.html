    Fixations by line¶

    Color each fixation by its text line.

    1. Select the bundled demo in Scanpath, then participant l37_1129 and trial l37_1129_2_1_1_Ele_r0. Start with Reset visualization, turn off Stimulus → Highlight words → Show.
    2. Open Fixations ▾ → Marker → Color and choose Text line.
    3. Keep Saccades and Stimulus on. The colors follow the word-box lines.

    Open the demo · All controls

    scanpath-studio render --sample \
  -p l37_1129 -t l37_1129_2_1_1_Ele_r0 \
  --color-by-line \
  --highlight-column '' \
  -o text-lines.html

    import scanpath_studio as sps

words, fixations = sps.load_sample_data()
pid, tid = "l37_1129", "l37_1129_2_1_1_Ele_r0"
fig = sps.plot_scanpath(
    words, fixations, pid, tid, color_by_line=True, highlight_column=None
)

sps.save_figure(fig, "text-lines.html")
