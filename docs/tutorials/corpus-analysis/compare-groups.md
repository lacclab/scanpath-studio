# Compare groups or conditions

Do two populations or conditions read differently?

1. [Define the pool](index.md#before-you-start), then open
   **:material/bar_chart: Corpus Analysis → Groups**.
2. Define one cohort — split a field, or build a filter set — and check that it
   looks right.
3. Turn on comparison, define the second cohort, and read **Group means &
   difference**. It compares the two cohorts' per-participant means and is
   descriptive: there is no significance test.
4. Read it with its denominator: the caption says how many participants are in
   each cohort and how many are in both. A participant in both contributes to
   both means, and then the standardized difference is not shown — see
   [how it is computed](../../computations.md#agg-effect-size).
