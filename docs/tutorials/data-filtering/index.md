# Filter data

Find the trials unsuitable for an analysis or a publication, decide which to
keep, and leave a record anyone can audit — without changing the data itself.
Use Scanpath Studio to:

- exclude or mark poorly calibrated, skimming or non-reading trials;
- exclude trials unsuitable for an analysis, for example those with
  out-of-bounds, very short or very long fixations;
- find the trials an analysis needs — for example, participants with a given
  native language and good calibration, or trials with many blinks.

Each page below is one task.

- :material-package-down:{ .lg .middle } **[Export the retained trials](export-the-retained-trials.md)**
