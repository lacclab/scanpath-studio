# Analyze one text

How was one text read — which words drew long fixations, and how do its readers
differ?

1. [Define the pool](index.md#before-you-start), then open
   **:material/bar_chart: Corpus Analysis → Per text** and pick the text.
2. Choose one familiar measure: total fixation duration for overall attention,
   first-pass reading time for initial processing, or regression rate for
   rereading.
3. Read the word profile on the stimulus, or against a word property such as
   surprisal. Set a minimum number of participants per word, so isolated
   observations do not appear as stable estimates.
4. Check how many participants contribute, and open a scanpath view to
   investigate surprising words.
