# See progression over time

Does reading change as a session goes on — with fatigue, practice, or as a condition takes effect? In **Corpus Analysis**:

| Question                                                    | View                                              |
| ----------------------------------------------------------- | ------------------------------------------------- |
| How does one participant's reading change over the session? | **Per participant → Per-trial trend**             |
| How do their fixation durations change over the session?    | **Per participant → Fixation duration over time** |
| How does a group's reading change over time?                | **Groups → Group trend**                          |

The trend follows the trials in the order your data's trial index records, so map that column when you add the dataset. Narrow the pool first to the participants or condition the question is about — see [Before you start](https://lacclab.github.io/scanpath-studio/tutorials/corpus-analysis/#before-you-start) — and keep the result as in [Keep the result](https://lacclab.github.io/scanpath-studio/tutorials/corpus-analysis/#keep-the-result).
