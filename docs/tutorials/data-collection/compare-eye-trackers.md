# Compare two eye trackers

Review the same text recorded with two trackers or setups.

1. [Import each recording](../../guides/loading-data/index.md#add-your-own-data)
   as a separate dataset with its own Recording setup.
2. Open the first dataset and select a trial in Scanpath.
3. Turn on Compare. In scanpath B's row, choose Dataset B and a trial of the
   same text.
4. Compare fixation placement, spread and missing stretches. Use side-by-side
   views for different screen sizes; an overlay requires matching screen coordinates.
