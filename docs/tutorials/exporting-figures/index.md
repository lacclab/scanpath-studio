# Export figures

Show a real scanpath in a paper, a talk or a supplement — or export a
consistent image set for downstream processing, such as training data for
models that generate scanpaths on images.

Each page below is one task.

<div class="grid cards" markdown>

- :material-eye-outline:{ .lg .middle } **[Choose the view](choose-the-view.md)**

    A scanpath, a heatmap, a comparison or a replay — and one clean figure.

- :material-image-move:{ .lg .middle } **[Export one figure](export-one-figure.md)**

    PNG, SVG, PDF or HTML, at the size the page needs.

- :material-movie-open-outline:{ .lg .middle } **[Export a replay](export-a-replay.md)**

    The animated reading as a GIF, an MP4 or an interactive page.

- :material-palette-outline:{ .lg .middle } **[Save the look as a design](save-a-design.md)**

    Reuse the same layers and colors on any trial, or share them.

- :material-folder-zip-outline:{ .lg .middle } **[Export a batch](export-a-batch.md)**

    The same view across many trials, with its provenance.

- :material-share-variant-outline:{ .lg .middle } **[Share the exact figure](share-the-figure.md)**

    A link, a settings file or the code that redraws it.

</div>
