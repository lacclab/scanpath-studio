    All controls¶

    Find every control in the Scanpath View, in the order it appears on screen. Search this page (Ctrl+F, or Cmd+F on a Mac) for what you want to change, such as colors, legends or axes.

    The view has two sets of controls:

    • The trial control bar, above the plot, decides what you see: the dataset, the trial, and which trials are in the list.
    • The plot controls, the column on the right, decide how it is drawn: each layer of the figure, its colors and sizes, and the figure as a whole.

    Use the tabs under the plot to annotate the current trial, read its context, compare readings, export a figure or share the view. For how the parts fit together, see the Scanpath visualization guide.

    For the corresponding Python keywords and CLI flags, use the figure options table.

    Trial control bar¶

    The bar above the plot: pick a dataset and a trial, step through the trials, and narrow, sort or label the list. Essentials has all of it except the slider, ⇅, the filter () and the trial summary table with its pencil (), which are in Full.

    Control What it does
    Select dataset The dataset the view shows.
    → Draw a scanpath Write a text and place its fixations by hand, as a new dataset.
    → Import files Upload your own Fixations and Words tables as a new dataset.
    Select trial The trial to show. Click it and type to narrow the list.
    Slider Move through the trials in the list.
    ◀ ▶ The previous or next trial. You can also use Left and Right from the page or plot background.
    ⇅ → Sort trials by Reorder the trial list by a statistic (such as reading time), a participant, text or condition field, or a column of a metadata table you attached.
    ⇅ → Descending Reverse that order.
    → Text / Participant Keep only these texts or participants. Empty keeps all.
    → a field of your data Keep only trials with these values, or, for a number, in this range.
    → By participant / By trial / By text The same, for the columns of an attached metadata table.
    → Favorites only Keep only starred trials.
    → With any of these tags Keep only trials with any of these tags.
    → Excluding tags Hide trials with any of these tags, such as To exclude.
    → ✕ Clear all filters Reset every filter in the panel.
    → Show the trial summary above the plot Show or hide the row of facts about the trial above the plot.
    → field lists Drag fields between Shown and Available to choose the trial summary's fields, and drag within Shown to reorder them. Available holds every field with one value per trial: participant, text and condition columns, the columns of any metadata table you attached, and statistics such as reading time and fixation count.
    → Field colors Give a field a highlight color. Its ✕ puts it back to the default gray.
    → Refresh fields Check again which fields have one value per trial.
    Screen and its ◀ ▶ On a trial recorded over several screens: the screen to show.

    Plot controls¶

    The column has four parts: Presets, Palette, Modes and Customize. The Presets and Palette tiles appear in both modes, and in Full, My presets sits below the preset tiles. Click beside any of the four labels to fold that part away, and the browser remembers it for your next visit. A folded Presets, Palette or Modes line still names the current choice. Under Modes, the switches turn on comparison and, in Full, Playback, and the arrow beside each switch opens its settings. Beside a tall figure, the column scrolls on its own.

    • Layers lists what the plot can draw. Click a layer’s name to edit its settings. The switch on the right shows or hides it. Filters & highlights applies to the current reading.
    • Axes chooses the X and Y fields and configures the coordinate grid.
    • Figure holds framing, titles, hover fields and legends.

    Use Find a setting in Full when you know what you want to change. Type a word such as arrow, font or margin and choose a result to open its controls. You can also browse Layers, Axes and Figure. Each menu shows the common adjustments first. Open a named section for finer changes.

    If you switch to Essentials while comparing readings, the comparison switch stays available.

    Playback settings¶

    Turn on the Animation tile, or the Playback switch under Modes, to replay the reading. Use the play and pause buttons and the time slider above the plot. Switch Animation off to return to your figure. For a saccades-only replay, open Full, leave Saccades on, and turn Fixations off. Each line appears when the reading reaches its next fixation. Heatmap and Raw gaze are available in static views. For playback and frame stepping from the keyboard, see Keyboard shortcuts. Open Playback settings in Full for these controls:

    Control What it does
    Speed How fast the video plays, from ×0.25 to ×8: ×1 is the participant's recorded pace, ×2 twice as fast, ×0.5 half as fast.
    Autoplay Start playing the animation as soon as the plot is shown. Otherwise it starts when you click play.
    Duration For information only: the trial's reading time, and how long the video runs at this speed.
    Smoothness How smooth the video is: Coarse, Standard or Fine. More frames play more smoothly but take longer to build. Moving either slider below makes it Custom.
    Frame timing → Frame interval Reading time between frames, in ms.
    Frame timing → Frame limit The maximum number of frames in the replay. For long trials, frames are spaced farther apart to stay within this limit.
    Frame count Shows the number of frames in this replay and the reading time between them.

    Compare¶

    Compare readings shows a second scanpath, B, beside or over this one. To find everyone who read the same text, open the Comparisons tab and match on text. Pick B in the trial control bar, above the plot. Its ▾ holds:

    Control What it does
    Layout Overlay both scanpaths, or give each a panel, Side by side or Top & bottom. In Animation, the comparison is an overlay.
    Overlay text In an overlay, whose word boxes and text are drawn: Both, A or B.
    Reading labels → Label A / Label B Each reading’s name in the comparison legend and above its panel in a split view, written with fields such as {participant_id}. Empty uses the automatic label.
    Reading labels → Available fields The fields a label can use.
    Trial arrows ◀ ▶ move both scanpaths at once.

    Presets, palette and saved presets¶

    Restyle the whole figure in one click, with a ready-made preset or one you saved:

    Control What it does
    Scanpath / Heatmap / Illustration Ready-made presets: fixations and saccades over the text, a word-box heatmap, or a clean schematic.
    Gaze over time Plot horizontal fixation position (pixels) against time (seconds since the first fixation onset). Each bar spans one fixation. Each displayed reading needs recorded fixation onsets. Compare shows the two readings in separate panels, with time starting at each reading’s first fixation.
    Custom Restore your last hand-edited figure, including its axes and palette. On first use, start with the figure on screen.
    My presets Your saved presets. Click one to apply it. renames it and deletes it.
    My presets → Save the settings on screen as a named preset, to apply again later in one click.
    My presets → Export / Import Download your presets as a file, or load a file of presets, to share a look with co-authors or move your presets to another computer. A preset in the file replaces yours of the same name.
    Palette Choose Colorblind-safe, Grayscale for print, or High contrast. The swatches preview each palette’s colors. For a grayscale comparison, A has filled markers and solid lines, and B has hollow markers and dashed lines.

    Fixations¶

    Click Fixations to edit the markers. The switch shows or hides them.

    Control What it does
    Color One color paints all fixations alike. A number such as duration uses a continuous scale. A category, such as a condition or a part of speech, keeps the same color in every trial of the dataset, even when filtering removes other categories. Up to 20 categories in the dataset get clearly different colors; with more, some colors are closer. The legend identifies missing values separately.
    color box With One color: the fixation marker color. With a number column: the color scale.
    Color range and color bar → Range When markers are colored by a number: the values at the two ends of the color scale. Auto fits each trial.
    Marker appearance → Shape Choose the fixation marker shape: circle, square, diamond, triangle, cross, X, star, hexagon or heart.
    Size Set the marker size range: the smallest and largest marker diameter, in px.
    Size by duration → Scale Choose how duration sets marker size: square root (the default), linear, log, or relative to this figure (its shortest to its longest fixation).
    Size by duration → Durations Set the durations (ms) that get the smallest and the largest marker. Not used on the relative scale.
    Opacity Set the fixation marker opacity. Lower it to see overlapping fixations.
    Marker appearance → Outline Set the width (px) and color of the ring around each marker. A width of 0 draws none.
    Color range and color bar → Show Show the color scale's bar, when markers are colored by a number.
    Color range and color bar → Vertical / Horizontal, Angle, Size, Thickness, Length Set the bar's direction (right of the plot or below it), its tick-label angle and size, and its thickness and length.
    Fixation index → Show Number each fixation in reading order.
    Fixation index → color, Size Choose the numbers' size in every view. For one scanpath, choose their color here. When comparing two scanpaths, each number uses its scanpath’s fixation color, including during replay.
    Marker appearance → Number position Put each number above its fixation, inside it, or below it.
    Position on the text → Snap to line Move each fixation up or down onto its line of text. Choose Show positions before snapping above the figure to see the original trial coordinates beside the illustration, on the same axes. Downloads use the illustration.
    Position on the text → Position Choose where on its line a snapped fixation sits.

    Saccades¶

    Click Saccades to edit the lines between fixations. The switch shows or hides the lines.

    Control What it does
    Color Choose what decides the saccade color: One color for all; Forward / regression, two colors; or By type, a color per saccade type (forward, skip, refixation, return sweep, regression), with a legend. Forward / regression and By type need a word ID for each fixation, the word it landed on, mapped as the Fixations table's Word ID (such as EyeLink's CURRENT_FIX_INTEREST_AREA_ID). Without one, every saccade is drawn as Off the text.
    color box With One color: the saccade line color.
    Types With Forward / regression or By type: the color of each group, such as regressions or return sweeps.
    Line and arrow appearance → Style Choose the saccade line style: solid, dashed, dotted or dash-dot.
    Width Set the saccade line width (thickness), in px.
    Line and arrow appearance → Opacity Set the saccade line and arrow opacity. Lower it to bring the fixations forward.
    Line and arrow appearance → Shape Choose the saccade shape. Straight draws lines. Arc draws arcs over the text, a schematic labeled Illustration.
    Direction arrows → Show Show saccade direction arrows: an arrowhead on each saccade, pointing where the eye went.
    Line and arrow appearance → Arrow size Set the saccade arrowhead size.

    Stimulus¶

    The Stimulus switch draws the text and the stimulus image. The text rows start from the dataset's Recording setup. Click Stimulus to adjust the text or image for this figure.

    Control What it does
    Text → Show Show the stimulus text, the words the participant read, at their place on the screen.
    Text → Redact Mask stimulus words and their text IDs. Other columns selected under Figure → Hover fields still travel with the HTML figure. Review those selections and the separate Stimulus image switch before sharing.
    Text appearance → Fit → Fit to word boxes Size the stimulus text from its word boxes, instead of a fixed font size.
    Text appearance → Fit → Spacing With Fit to word boxes on: the distance between lines, in font sizes. The font size is that distance divided by this value, so 3 leaves a blank line above and below.
    Text appearance → Size With Fit to word boxes on: the size of the axis and legend text, in px. Off: the stimulus text's size too, in px or pt.
    Text appearance → Font Choose the stimulus text font (typeface). Other font… takes any font name.
    Text appearance → Color → text color Choose the stimulus text color.
    Word highlights → Show Highlight words in the stimulus text, such as the answer span.
    Word highlights → word column Choose which words to highlight: a true/false word column, such as the critical span.
    Word highlights → Style Mark text changes the color of the selected words. Mark border outlines the span. Both have a color picker. Underline draws a line beneath each selected word in the current text color. A border can stay visible with text and ordinary word boxes hidden. Each split panel outlines its own stimulus.
    Stimulus image → Show Show the stimulus image, the screen as shown in the experiment, under the scanpath.
    Stimulus image → File Upload a stimulus image (PNG, JPEG, GIF or WebP) to draw under the scanpath. It replaces the dataset's image and is not included in Share links.
    Stimulus image → Opacity Set the stimulus image opacity. Lower it so the scanpath reads over it.
    Stimulus image → Offset → X / Y Move (nudge) the stimulus image left, right, up or down, in px, to line it up with the word boxes.
    Stimulus image → Scale Resize (scale) the stimulus image so its text matches the word boxes.

    Word boxes¶

    The Word boxes switch draws each word’s interest area. Click Word boxes to set its outline and fill.

    Control What it does
    Outline color Choose the word box outline (border) color.
    Outline opacity Set the word box outline opacity. 0 hides the outlines.
    Fill color Choose the word box fill color, inside each box.
    Fill opacity Set the word box fill opacity. 0 draws outlines only.

    Heatmap¶

    The Heatmap switch shows where reading concentrated. Click Heatmap to choose the measure, colors and scale.

    Control What it does
    Draw as Choose the heatmap style: Word boxes colors each word box, Smoothed blurs the fixations with a Gaussian. Compare always uses word boxes.
    Smoothing and scale → Blur For Smoothed: how far each fixation spreads, in px. Auto picks it from the size of the data.
    Measure Choose what the heatmap measures: total fixation duration (dwell time), or Fixation count.
    Colors Choose the heatmap colors (color scale).
    Smoothing and scale → Scale Choose a linear or log heatmap scale.
    Smoothing and scale → Range A word-box legend gives the reading’s dwell-time or count limits. Choose Use this heatmap range for other trials above the plot to keep those limits. Smoothed heatmaps scale to each figure’s peak.
    Opacity Set the heatmap opacity. Auto uses 0.5 for word boxes and 0.45 for smoothed.
    Color bar → Show, orientation, Angle, Size, Thickness, Length Show the heatmap color bar, and set its orientation, label angle and size, thickness and length.

    Raw gaze¶

    The Raw gaze switch draws the recorded gaze samples. Click Raw gaze to set their appearance.

    Control What it does
    Sample color A single reading uses sample time, or sample order when timestamps are missing. Choose the fallback color here. In Compare, each reading has its own color.
    Dot size Set the raw gaze sample marker size.
    Opacity Set the raw gaze sample opacity.

    To inspect samples from one reading, open Axes → Axis layout. Choose Horizontal gaze position over recorded time, Vertical gaze position over recorded time, or a recorded pupil measurement. These presets turn on Raw gaze. A recording without timestamps offers sample number on the horizontal axis.

    In the OneStop demo, the clock starts at trial onset and each screen's samples start when the reader sees that screen. A sample with missing gaze coordinates has no pupil area either, so the pupil chart shows a gap there. The raw table and its exports keep those samples.

    Filters & highlights¶

    An Active label appears beside Filters & highlights when either reading has a fixation window, highlight or filter in effect. The trial-list filter selects whole readings.

    Control What it does
    Fixations → Index range Show only some fixations: a range of the reading order, such as fixations 10 to 40.
    Keep this range across trials Keep that fixation range when you move to another trial. Off, it applies to this trial only, and the next trial shows all its fixations.
    Short / Long Find fixations shorter or longer than the cutoff (80 ms and 800 ms by default). Show keeps the usual marker and Highlight changes its appearance. Hide removes the marker and skips the fixation in replay and fixation-index sequences. Replay lines connect the remaining fixations. Spatial saccade lines and heatmaps on static plots still use the hidden fixation.
    Outside the text Highlight or hide fixations that land in no word box.
    Near a blink Highlight or hide fixations at or next to a blink (needs a blink column).
    Highlight markers → shape and color Choose the marker shape and color of each highlighted fixation kind.
    Saccades → Types Show only some saccade types, such as regressions or return sweeps. Empty draws all. Needs a word ID for each fixation, as for coloring saccades by type.

    Axes¶

    Choose a chart preset, or set the X and Y fields individually. Open Coordinate grid to style the screen grid.

    Control What it does
    Axis layout Plot horizontal or vertical screen position by fixation index or elapsed time, or compare fixation index with elapsed time or duration. Connect fixations traces the windowed index sequence, including with fixation markers hidden. Hide filters also apply to the line. On an elapsed-time chart, each bar spans one fixation’s duration. Zero is the trial’s first recorded onset, including when viewing a later screen or a narrower fixation window.
    Choose axis fields → horizontal / vertical Choose fixation fields or raw gaze measurements. For samples, try pupil size or gaze position against recorded time or sample number. Each layer draws the fields it contains. Screen Y increases downward. Screen X and Y restores the stimulus view. Static comparisons use shared ranges in side-by-side or stacked panels. Each reading keeps its own elapsed-time origin. Animation uses screen coordinates.
    Grid → Show Show a grid of screen coordinates, in px.
    Grid spacing and labels → interval Set the grid spacing (interval), in px, or let Auto choose it.
    Grid spacing and labels → label size Set the grid label (tick label) font size.

    Each dot is a fixation. The clusters step down as the reader looks lower on the screen. Around 39 seconds, the reader looks back near the top.

    Figure¶

    Open Screen & framing, Title & labels, Hover fields, or Legends.

    Control What it does
    Screen & framing → Background Choose the figure background color.
    Crop to data Crop (zoom) the figure to the part of the screen with data, instead of the whole screen.
    Margins and border color → crop margin Set the crop margin: the space around the data when cropping. Auto uses 5% of the data's width and height, at least 20 px.
    Show plot border, Margins and border color Show a 1 px border around the plot area, and choose its color. It marks the edge of the screen, or, with Crop to data, the edge of the cropped area.
    Illustration label → When to show the label Choose when the figure carries an Illustration note, saying it does not show the recorded positions. Auto adds it when a setting changes the geometry or the data (such as snapping fixations to a line or drawing saccades as arcs), Show always, Hide never.
    Illustration label → Label text Write the Illustration label's text. Empty writes "Illustration ·" followed by the reasons.
    Show title, title text and Text size and color Add a figure title above the plot, and set its font size. {field} inserts a value of the trial.
    Show caption, caption text and Text size and color Add a figure caption below the plot, and set its font size and color. {field} works here too.
    Credit → Show Add a small Made with Scanpath Studio line under the plot.
    Hover fields → Fields on a word / Fields on a fixation Choose the hover fields: what the tooltip shows when the mouse is over a word or a fixation.
    Legends → Show on the figure Show or hide each legend the figure draws: Compare (A/B), Saccade types, Fixation colors, Fixation sizes or Text highlight. The fixation size legend starts hidden. Select Fixation sizes to include it in a saved figure.
    Legend position and style → Position Choose the legend position: a corner, the middle of an edge, or down a side, outside or inside the plot.
    Legend position and style → Arrangement Choose the legend arrangement: Stacked or Side by side.
    Legend position and style → Text size Set the legend text (font) size, in px. Empty uses the figure's text size.

    Reset¶

    At the foot of Full plot controls, use the arrows beside Reset to step through your last 30 plot changes. Presets and a confirmed reset each count as one change.

    Control What it does
    Undo Restore the previous plot settings for the current dataset. Switching trials keeps you on the newly selected trial.
    Redo Reapply the change you undid. Making a new plot edit clears the redo list.
    Reset After you confirm, reset every plot setting to its default, Filters & highlights included. Annotations, trial filters, data and the selected trial stay.

    Changing datasets starts a fresh history. A trial-specific fixation window drops out of history when you leave that reading.

    In Compare¶

    With Compare on, scanpath B gets a second row in the trial control bar, and several menus split into a Scanpath A and a Scanpath B group.

    Control What it does
    Dataset B Choose the dataset scanpath B comes from. To reopen a shared comparison with PoTeC or OneStop, the recipient needs the corpus on their computer. If the link opens only A, open the named corpus as the main dataset to locate or download its files, then reopen the link.
    Trial B, slider, ◀ ▶ Choose scanpath B's trial: 📄 marks the same text, 👤 the same participant.
    Screen B On a trial recorded over several screens: B's screen to show.
    ⇅ on B's row Sort scanpath B's trial list, apart from A's. The default, Same text, then same participant, lists trials of A's text first, then A's participant, then the rest. You can also sort by any field, as on A's row.
    on B's row Filter scanpath B's trials, apart from A's.
    Layers → Fixations → Scanpath A / B → Color, Size, Opacity Choose each scanpath's fixation marker color, size range and opacity. When the markers are colored by a column, Color becomes Outline.
    Layers → Saccades → Scanpath A / B → Color, Style, Width Choose each scanpath's saccade line color, style and width.
    Layers → Word boxes → Scanpath A / B → Line, Fill Choose each scanpath's word box outline and fill colors and opacities.
    Layers → Heatmap → Scanpath A / B → Colors Choose each scanpath's heatmap colors (color scale).
    Layers → Raw gaze → Scanpath A / B → Color Choose each scanpath's raw gaze sample color.
    Layers → Filters & highlights → Reading B Set scanpath B's fixation range, fixation highlights and saccade types.

    Under the plot¶

    The tabs under the figure. Essentials has Export, for the current figure, and Share; the other tabs and the export bundle are in Full.

    Tab Control What it does
    Annotations Favorite Star the trial as a favorite, to find it again with Favorites only in the trial filters.
    Tags / Add a tag Tag the trial, with an existing tag or a new one, such as exclude. Tags let you filter the trial list later: the in the trial control bar keeps or hides trials by tag.
    Notes Write a free-text note on the trial.
    Stimulus & context Fields → Context fields Choose the trial context to show, such as the text's title, a question or an answer.
    Fields → Highlighted spans Choose true/false word columns to highlight in the text, each with a summary line.
    Comparisons Match field Compare with other trials: show the trials that share this trial's value of a field, such as the same text.
    Columns Set how many comparison panels per row, from 1 to 4.
    Export Download format Export (download) the figure on screen as PNG, SVG, PDF or HTML, or the animation as an HTML, GIF or MP4 video.
    Width, unit, DPI Set the PNG export size for print: width (mm or in) and resolution (DPI). A blank width writes the figure at three times its screen size.
    Trials to include Choose which trials to export in the bundle: This trial, All filtered trials, All trials of one participant, All trials of one text, or All trials, ignoring filters.
    Formats / Tabular data / Table format Choose the bundle's figure formats, the data tables to include, and their format (CSV, Parquet or both).
    Layers as separate files Export each visual layer (fixations, saccades, word boxes…) as a separate file, to stack in a vector editor.
    Annotations (JSON) / Settings file (JSON) Settings file: beside each trial's figure, a plot_config.json recording how it was drawn (layers, colors, sizes, screen, title and caption), so the figures are documented. Annotations: one annotations.json with the exported trials' favorites, tags and notes, which Data Management → Current dataset → Annotations can import again.
    File path pattern Set the file names inside the export bundle.
    Build export Build the export bundle (a zip) to download.
    Share Link Copy a link that reopens this trial and its settings. The bundled demo works anywhere. A public dataset has to be downloaded on the recipient's side. For each dataset you imported, send its data files and setup file (Current dataset → Edit dataset → Download setup file) so they can add it under the same name. If they have A but still need B for a comparison, the link opens A and names the dataset to add. On your own computer the link still works after either dataset is renamed. A localhost link opens where the app runs at the same address.
    Code → Python / CLI, Show every option Get the Python or command-line code that redraws this figure, for scripts and reproduction.
    Settings file → Download settings / Restore settings Save the plot settings to a file, or load (restore) a saved settings file.
