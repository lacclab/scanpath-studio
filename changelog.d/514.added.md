Scanpath Studio is easier to cite: every exported figure, replay and page (PNG, SVG, PDF, HTML, GIF, MP4) carries the citation in its file metadata, the export bundle adds a `CITATION.bib` and a README *Cite* section naming the corpus too (OneStop, PoTeC), `scanpath-studio cite` and `sps.cite()` print BibTeX, APA, RIS, CSL-JSON or a one-line figure credit, and Share → Code opens with a citation comment.
