# Export one figure

Save a scanpath, heatmap or comparison at the size you need.

## 1. Choose the view { #1-choose-the-view }

Select a trial in Scanpath. Choose a design preset or adjust the layers in
Plot controls. Turn on Compare if the figure needs two readings.
Check that text and markers are readable and nothing is clipped.

## 2. Set the format and size

Open Export → Current figure.

| Output | Format |
| --- | --- |
| Image | PNG |
| Vector figure | SVG or PDF |
| Interactive figure | HTML |

For a print PNG, set Width and DPI. For HTML that opens offline, tick
Self-contained HTML.

## 4. Reuse the design or share the figure

- My designs in Plot controls saves the look for other trials.
- Share → Link reopens the trial and settings; uploaded data must be loaded separately.
- [Share → Code](../../guides/exporting/index.md#from-the-app-to-a-script) gives Python or CLI code to redraw the figure.
- Share → File saves the settings to load again.
