Scanpath Studio is easier to cite: a Cite button beside the figure, replay and bundle downloads and in Share → Code gives a figure credit, APA, BibTeX and .bib / .ris files (naming OneStop or PoTeC too when the data comes from them), every exported figure, replay and page (PNG, SVG, PDF, HTML, GIF, MP4) carries the citation in its file metadata, the export bundle adds a `CITATION.bib` and a README *Cite* section, and `scanpath-studio cite` / `sps.cite()` print it headlessly.
