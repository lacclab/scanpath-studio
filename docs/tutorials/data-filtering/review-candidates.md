# Review candidate trials

For each candidate, inspect the default scanpath and turn on **Animate** only
when timing helps. Open **:material/filter_list: Filters & highlights →
:material/blur_on: Fixations** in the plot rail and set **Highlight** for:

- out-of-bounds points;
- fixations below or above your duration thresholds.

Highlighting keeps the whole trial visible, so you judge the trial rather than
hide its problems. Use **Fixation index range** in the same place to show only
part of the trial.
