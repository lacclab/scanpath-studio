What this page is

The archive of the Scanpath Studio improvements tracker. Every item ever raised is here, with its full write-up and code anchors, under its stable ID (CMP-3, VIZ-31) — the IDs the docs, the plans/ notes and the git history cite. Read-only: nothing on this page can be edited, and there is no server API behind it any more.

Open work lives on GitHub Issues since 2026-08-20 (ENG-32). The 26 items that were still live moved there and each shows an ↗ #N link on its card; the 320 closed ones stayed behind, because their value is the write-up, not the workflow.

Finding things

  • Search by ID, title, or any word in a write-up. / focuses the box.
  • #CMP-3 in the URL jumps straight to that item and expands it — un-archiving the view if it needs to. Every #ID in a write-up is a link that does the same.
  • Archived items are hidden until Show archived; the group, status, priority and owner facets narrow what is on screen.

Write-up shape

Four sections, in this order, so the ask stays legible next to what shipped. They are separate fields on the item (request, whatWasDone, whatsLeft, background) rather than bold leads inside one blob of prose:

  • Request — what was asked for, in the asker's terms. Always present.
  • What was done — what actually shipped.
  • What's left — the developer's remaining work, and nothing else.
  • Background (technical) — code anchors, design calls, gotchas, related IDs. The internal half, kept out of the first three.

An optional statusNote renders above them as the item's lede. Older archived items hold a single body array instead; both render. The amber Waiting on you box is the decisions field — the calls that were open when the item was last touched. On a migrated item those are now the issue's Waiting on you checklist, which is where they get answered.

The same shape carried over to GitHub unchanged: an issue body is the write-up, the six statuses are status:* labels, the groups are area:* labels, and closing an issue is the sign-off — so the approval gate (implemented → status:review, open, until the user signs off) still holds.

Serving it

Double-click tracker/start.command (macOS) or tracker/start.bat (Windows), or run python3 tracker/server.py — a plain static server, so fetch works. Opening index.html as a file:// page cannot read state.json and will say so.
