# Optimize data collection

- **[Check a session](https://lacclab.github.io/scanpath-studio/tutorials/data-collection/check-a-session/index.md)**

  Inspect a pilot or completed recording.

- **[Compare two eye trackers](https://lacclab.github.io/scanpath-studio/tutorials/data-collection/compare-eye-trackers/index.md)**

  Review recordings of the same text.

- **[Audit an experimenter](https://lacclab.github.io/scanpath-studio/tutorials/data-collection/audit-an-experimenter/index.md)**

  Review sessions by who collected them.

Start with a [loaded dataset](https://lacclab.github.io/scanpath-studio/guides/loading-data/#add-your-own-data). To apply exclusion decisions after reviewing, use [Filter data](https://lacclab.github.io/scanpath-studio/tutorials/data-filtering/index.md).
