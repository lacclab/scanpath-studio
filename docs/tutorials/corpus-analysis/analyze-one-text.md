# Analyze one text

Compare how participants read the words of one text.

1. [Select the trials](index.md#before-you-start), then open Corpus Analysis → Per text.
2. Pick a text and an available reading measure.
3. Choose a word profile on the stimulus or a plot against a word feature,
   such as surprisal if that column is present.
4. Set the aggregation, spread and minimum participants per word. Check the
   counts before interpreting differences.
5. [Download the table and recipe](index.md#keep-the-result).
