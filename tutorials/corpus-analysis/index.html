    Analyze a corpus¶

    • Analyze one text

      Compare word-by-word measures across readers.

    • Compare groups or conditions

      Inspect group means and differences.

    • See progression over time

      Inspect trends within or across trials.

    Before you start¶

    Open a dataset and set the trial filters for your question. Word-level views need reading measures in the Words table; the bundled demo includes them. For comparisons across readers, the same text must have the same text ID.

    Keep the result¶

    Download this table (CSV) saves the values. Download the recipe (JSON) saves the dataset name, filters, analysis choices and counts. Keep the source data separately so the result can be reproduced.

    To draw a summary with Python or the CLI, see Plot a summary in code.
