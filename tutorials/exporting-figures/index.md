# Export customized figures

Show a real scanpath in a paper, a talk or a supplement — or export a consistent image set for downstream processing, such as training data for models that generate scanpaths on images. Each page below is one task.

- **[Export one figure](https://lacclab.github.io/scanpath-studio/tutorials/exporting-figures/export-one-figure/index.md)**

  A scanpath or a heatmap for a paper or a talk, at the size the page needs.

- **[Export a replay](https://lacclab.github.io/scanpath-studio/tutorials/exporting-figures/export-a-replay/index.md)**

  The animated reading as a GIF, an MP4 or an interactive page.

- **[Export every trial](https://lacclab.github.io/scanpath-studio/tutorials/exporting-figures/export-every-trial/index.md)**

  The same view across many trials, with its provenance.
