# Compare two eye trackers

Review the same text recorded with two trackers or setups.

1. [Import each recording](https://lacclab.github.io/scanpath-studio/guides/loading-data/#add-your-own-data) as a separate dataset with its own Recording setup.
1. Open the first dataset and select a trial in Scanpath.
1. Turn on Compare. In scanpath B's row, choose Dataset B and a trial of the same text.
1. Compare fixation placement, spread and missing stretches. Use side-by-side views for different screen sizes; an overlay requires matching screen coordinates.
