# Optimize data collection

Problems in eye-tracking data are cheapest to fix before and during collection.
Use Scanpath Studio to:

- **pilot your setup:** your eye tracker and software, and the stimulus layout
  (font, spacing), before you commit to them;
- **check that the setup is correct:** calibration problems often only show up
  in a plot of the data, and during collection the data moves too fast to see
  every issue;
- **train and supervise experimenters:** problems such as a participant blinking
  often are hard to notice live but easy to see in the plots, so new
  experimenters can learn from them and the person overseeing collection can
  check each session.
