# Analyze a corpus

- **[Analyze one text](https://lacclab.github.io/scanpath-studio/tutorials/corpus-analysis/analyze-one-text/index.md)**

  Compare word-by-word measures across participants.

- **[Compare groups or conditions](https://lacclab.github.io/scanpath-studio/tutorials/corpus-analysis/compare-groups/index.md)**

  Inspect group means and differences.

- **[See progression over time](https://lacclab.github.io/scanpath-studio/tutorials/corpus-analysis/progression-over-time/index.md)**

  Inspect trends within or across trials.

## Before you start

Open a dataset and set the trial filters for your question. Word-level views need [reading measures in the Words table](https://lacclab.github.io/scanpath-studio/guides/loading-data/#reading-measures); the bundled demo includes them. To compare participants on one text, their trials of that text must share one text ID.

## Keep the result

**⬇ Download this table (CSV)** saves the values. **⬇ Download the recipe (JSON)** saves the dataset name, the trial filters, the analysis choices and the counts. The recipe names the dataset but holds none of its data, so keep the source data to reproduce the result.

To draw a summary with Python or the CLI, see [Plot a summary in code](https://lacclab.github.io/scanpath-studio/guides/corpus-workspace/#plot-a-summary-in-code).
