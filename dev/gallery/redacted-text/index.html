    Redacted text¶

    Show where the text was without showing what it said. Each word is drawn as a rounded block over its letters. Words are also hidden in tooltips.

    1. Open your data in the Scanpath View and pick a trial in Select trial.
    2. In Stimulus ▾ → Text, tick Redact. The blocks take the text color.

    Open the demo · All controls

    scanpath-studio render --sample \
  -p l37_273 -t l37_273_2_1_1_Ele --screen Paragraph \
  --redact-text --highlight-column '' \
  -o redacted-text.html

    import scanpath_studio as sps

words, fixations = sps.load_sample_data()
pid, tid = "l37_273", "l37_273_2_1_1_Ele"
fig = sps.plot_scanpath(
    words, fixations, pid, tid, screen="Paragraph", redact_text=True
)

sps.save_figure(fig, "redacted-text.html")
