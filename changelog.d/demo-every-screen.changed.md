The bundled demo keeps every screen of each reading — title, question preview, paragraph, question, answers and feedback — each with the experiment's own stimulus image placed where the experiment drew it, and raw gaze for every screen. A demo trial opens on its first screen and numbers its fixations across all its screens; a demo link or settings file saved by an earlier release still opens the paragraph on the same fixations, but a script must now name the paragraph (`--screen Paragraph`, `screen="Paragraph"`) to draw it, a fixation-index window counts from the trial's first screen, and the demo's export bundle files each screen under `screens/`.
