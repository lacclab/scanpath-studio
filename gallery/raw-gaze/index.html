    Raw gaze¶

    Samples under translucent fixations. The demo samples are synthetic.

    1. Select the bundled demo in Scanpath, then participant l37_1129 and trial l37_1129_2_2_2_Adv_r0. Start with Reset visualization.
    2. Turn on Raw gaze and turn off Saccades.
    3. In Fixations ▾ → Marker → Opacity, choose 0.35 so the samples show through.

    Open the demo · All controls

    scanpath-studio render --sample \
  -p l37_1129 -t l37_1129_2_2_2_Adv_r0 \
  --sample-raw-gaze --fixation-opacity 0.35 --no-saccades \
  -o raw-gaze.html

    import scanpath_studio as sps

words, fixations = sps.load_sample_data()
pid, tid = "l37_1129", "l37_1129_2_1_1_Ele_r0"
raw_gaze = sps.load_sample_raw_gaze()
fig = sps.plot_scanpath(
    words,
    fixations,
    "l37_1129",
    "l37_1129_2_2_2_Adv_r0",
    raw_gaze=raw_gaze,
    fixation_opacity=0.35,
    show_saccades=False,
)

sps.save_figure(fig, "raw-gaze.html")
