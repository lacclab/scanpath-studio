# Correct vertical drift

!!! note "Not available in this build"
    Vertical drift correction and the **Line assignment** subtab are not exposed
    in the released app (PRE-21): the feature works, but it is not yet fully
    integrated, and a half-wired control invites results it can't support. The
    code ships with the package — set `SCANPATH_EXPERIMENTAL=1` before starting
    the app (or the CLI / Python API) to turn it back on.

When enabled, see
[Correct vertical drift](../guides/scanpath-visualization.md#correct-vertical-drift)
for the controls and behavior.
