# Record the review

Turn what you saw into a record you can return to.

1. Open **Annotations** under the plot for the selected trial:
    - star a good example;
    - add a tag such as `calibration`, `blink`, `setup` or `review`;
    - write one sentence describing the evidence and the action.
2. Move through the participant's trials with the trial picker.
3. Save the record: open :material/database: **Data Management → Annotations**
   and select **Export**. The file keeps your stars, tags and notes;
   **:material/share: Share → File** keeps the view settings beside it. To
   return to a trial from its note, select **Open** on its row there.
