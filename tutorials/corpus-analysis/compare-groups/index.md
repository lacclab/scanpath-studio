# Compare groups or conditions

Compare a reading measure between two cohorts.

1. [Select the trials](https://lacclab.github.io/scanpath-studio/tutorials/corpus-analysis/#before-you-start), then open Corpus Analysis → Groups.
1. Turn on Compare a second group.
1. Split a field or define independent filters for the two groups.
1. Choose Group means & difference and a measure. Check the number of participants in each group and any overlap. A standardized difference is shown only for non-overlapping groups.
1. [Download the table and recipe](https://lacclab.github.io/scanpath-studio/tutorials/corpus-analysis/#keep-the-result).

The comparison is descriptive; it does not run a significance test. For a recorded example, see [Analyze one text](https://lacclab.github.io/scanpath-studio/tutorials/corpus-analysis/analyze-one-text/index.md).
