# Compare groups or conditions

Compare a reading measure between two cohorts.

1. [Select the trials](index.md#before-you-start), then open Corpus Analysis → Groups.
2. Turn on Compare a second group.
3. Split a field or define independent filters for the two groups.
4. Choose Group means & difference and a measure. Check the number of
   participants in each group and any overlap. A standardized difference is
   shown only for non-overlapping groups.
5. [Download the table and recipe](index.md#keep-the-result).

The comparison is descriptive; it does not run a significance test.
For a recorded example, see [Analyze one text](analyze-one-text.md).
