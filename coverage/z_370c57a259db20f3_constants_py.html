10# --- PRE-21: features that are built but not fully integrated ---------------- 

11# Vertical drift correction (the PRE-3 port of Carr et al. 2021) and the NLD 

12# similarity scoring under 🔬 Comparisons both work, and both are half-wired: 

13# the similarity table still shows three metrics as "Not yet computed", and the 

14# drift-correction subtab's follow-ups (PRE-9, PRE-10) are unfinished. Shipping 

15# them visible invites users to lean on them, so ahead of publication they are 

16# gated off — a **visibility gate, not a removal**: `alignment.py` and 

17# `similarity.py` stay exactly where they are and stay reachable for us. 

18# 

19# Polarity is the opposite of `app.public_datasets_enabled`: these default 

20# **off** and the env var turns them on. Read at *call time*, which is both what 

21# lets a test toggle them and what stops a stale import-time read from making 

22# one surface disagree with another.

268# --- VIZ-18 · selectable palettes -------------------------------------------- 

269# These figures don't only get looked at on the screen they were made on: they go 

270# into papers (printed, sometimes in black & white) and are read by colourblind 

271# viewers. One palette can't serve all of that, so the colour defaults are a 

272# *choice* rather than a constant. 

273# 

274# A palette is a preset, not a second rendering path: picking one writes the 

275# ordinary per-element colour keys, so every existing picker still overrides it 

276# and every surface (deep link, Save & restore, CLI, API) carries the resulting 

277# colours with no new plumbing. ``palette_settings`` returns the figure-kwarg

357def palette_settings(name: str) -> dict: 

358 """Figure-kwarg colour settings for palette ``name`` (falls back to Default). 

359 

360 Returns a fresh dict (nested ``saccade_class_colors`` copied too), so callers 

361 can mutate the result without corrupting the registry. 

362 """ 

363 entry = PALETTES.get(name) or PALETTES[DEFAULT_PALETTE] 

364 settings = {k: v for k, v in entry.items() if k != "description"} 

365 settings["saccade_class_colors"] = dict(settings["saccade_class_colors"]) 

366 return settings

523 """An ISO language code (or comma-joined list of them) as display names. 

524 

525 A multilingual corpus records several codes in one field (`"en,de,ru"` — MECO, 

526 celer), so each part is mapped and the list re-joined. An unrecognised code 

527 renders as itself: it still identifies the language to anyone who knows it, 

528 which "Unknown" does not. A blank/absent value gives ``""`` so the caller can 

529 drop the caption rather than print an empty label. 

530 """ 

531 text = str(value or "").strip() 

532 if not text: 

533 return "" 

534 parts = [part.strip() for part in text.split(",") if part.strip()] 

535 return ", ".join(LANGUAGE_NAMES.get(part.lower(), part) for part in parts)
